THPT Score Explorer 2026

Hệ thống web tra cứu điểm và xếp hạng lớp 10, xử lý dữ liệu từ khâu thu thập, giải mã, chuẩn hóa đến API lookup và ranking.

Bài toán → giải phápDữ liệu điểm cần được xử lý và tra cứu nhanh → Next.js + TypeScript + Supabase + PostgreSQL + Python + Vercel
Next.jsTypeScriptSupabasePostgreSQLPythonVercel
  • Xây dựng /api/lookup kiểm tra SBD 8 chữ số, truy vấn view scores_with_tohop, ghi log tìm kiếm và cache kết quả.
  • Thiết kế hàm PostgreSQL get_rankings và API /api/rank cho tổng điểm cùng 5 tổ hợp A00, A01, B00, C00, D01 ở cấp tỉnh/toàn quốc.
  • Tự động thu thập và chuẩn hóa dữ liệu bằng AES-GCM, ThreadPoolExecutor tối đa 20–30 workers, xuất JSON/CSV và nhập Supabase theo batch 500 bản ghi.
  • Tiền xử lý lop10.json với 13.290 hồ sơ local, tính rank theo tỉnh/trường và hiển thị thống kê theo hội đồng thi; ứng dụng được triển khai trên Vercel.
